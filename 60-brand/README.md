## The `DES-R` namespace

| ID | Requirement |
|----|-------------|
| **DES-R1** | The product name MUST be written capitalised as "Beatrax" in prose, including mid-sentence. |
| **DES-R2** | Brand primitives MUST be defined once and consumed by every surface; no surface may introduce its own. |
| **DES-R3** | Every primitive MUST have both a light and a dark value. |
| **DES-R4** | Every themed surface MUST carry a dark companion for every light-mode colour utility, enforced by test in the product. |
| **DES-R5** | Colour MUST NOT be the only carrier of meaning; status, direction, and severity MUST also carry a label, a shape, or an icon. |
| **DES-R6** | The voice MUST be British-leaning, calm, and precise, on every surface. |
| **DES-R7** | System copy MUST NOT use exclamation marks or manufactured urgency. |
| **DES-R8** | Copy MUST NOT claim a protection the implementation does not provide. |
| **DES-R9** | Motion MUST be restrained and MUST NOT be required to understand a surface. |
| **DES-R10** | Amounts MUST be formatted for the user's locale, including separators and symbol position. |
| **DES-R11** | The name MUST NOT be used in a way that implies endorsement of a fork or derivative. |
| **DES-R12** | Screenshots used publicly MUST come from the product repository and MUST show a version that exists. |

## The character

The product is a **calm** one. It handles the most anxiety-inducing subject most
people have, for people who have already given up on doing it by hand. Every
choice — density, colour, motion, wording — follows from that.

Concretely: content-first rather than chrome-first; quiet chart defaults; a
dashboard that shows what needs attention without shouting; and no
congratulatory interstitials for having looked at your own money.
